# Frontend agent rules

Read root `../AGENTS.md`. Preserve current React workspace; avoid extra dashboards. Keep image uncropped, click-to-point overlay aligned with intrinsic pixel coordinates, correctable endpoints, scale reference validation and explicit status. Provide Indonesian and English documentation with equivalent coverage.
